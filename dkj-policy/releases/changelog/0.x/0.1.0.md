# Changelog Releases

The four house-style tags brought together as the first X.Y.Z release

The first release numbered as `X.Y.Z`. It brings together the four hand-set house-style tags
`house-style-v1` to `house-style-v4` as one release, and from here on the brand book releases as
`vX.Y.Z` only.

What the house style holds at `v0.1.0`:

- **Tokens and themes**: a shared base layer (typography, spacing and type scales, radius, motion) and
  twelve colour themes, each built on a nine-step `--primary-1`..`--primary-9` scale, with dark themes
  that mirror the light themes' ground.
- **The stylesheet and theme script**: `house-style/house-style.css` and `house-style/house-theme.js`,
  usable from a React app and from a Claude Artifact, with the settings button (`DKJTheme.settings`).
- **Components**: the house app components, the button family (including the disabled state), charts,
  data tables, stat tiles, badges and `BadgeList`, and the badge-led card heading.
- **The Repo dashboard pattern**: house classes for every block of the dashboard and the reference page
  `house-style/patterns/repo-dashboard.html`, so a repo without React builds the same form.
- **The gate**: a check that every `var(--x)` the code uses is defined.

The full per-PR history of the four tags stays readable in their own release notes, linked from the
[release history](../../history.md).
