# Release notes v0.3.0 🚀

**Date:** 2026-10-18\
**Type:** Minor\
**For whom:** consumers of this product, and colleagues in the organisation -- one section each

The Repo hub: a new name, a Pages block, a default theme per repo, and a full preview width

## What changed

**Nothing breaks.** No token, class, component or file is renamed or removed, so taking the new copy of
`house-style.css` and `house-theme.js` needs no migration. The one action is the rename below, and the
default theme is one attribute when you are ready for it.

### Rename your index page to "Repo hub"

The index page of a DKJ-Solutions dev server is now called **Repo hub** instead of Repo dashboard: it gets
you to the page you want, and the pages below it can be dashboards. **What you do:** change your index
`h1`, its `<title>` and the first crumb of your breadcrumb bar from "Repo dashboard" to "Repo hub". File
names, components, classes and URL paths stay as they are.

### Give your app its own default theme

Every DKJ-Solutions repo now has a default theme of its own, and no two are the same, so you can tell the
apps apart before anyone picks a theme. **What you do:** add one attribute to your `<html>`, for example
`<html data-theme-default="teal">`, with the theme `house-style/README.md` lists for your repo. A user's
own choice still wins. Until you add it, your app keeps following the light/dark pair as before.

### List your repo's own pages on its Repo hub

Your Repo hub can now carry a **Pages** card right under the intro, with one link row per page of your
repo: a label, an optional one-line description and a chevron. Use the `PageLinks` component in React, or
the `.menu-item` markup the pattern page shows. No action needed: a repo with no page besides `/` and its
product leaves the card out.

### Judge a preview at the full width of your screen

In the brand book, the preview settings have a third width, `full`, next to `fluid` and `phone`, and it is
the default. The Repo hub and the dashboard previews carry the Width toggle too. No action needed.

## What it is worth

The dev servers of all DKJ-Solutions repos now open on a page with one fixed name and one way to reach a
repo's own pages, so nobody has to explain where an app's pages are. The default theme per repo tells eight
apps apart at a glance, which matters when several are open side by side. Both are one change each for a
repo that takes this release, written into the house style rather than agreed per repo.

The release itself took **2m 17s** end to end, measured from the start of the cut (08:31:05 UTC) to the
last attachment landing (08:33:22 UTC). The cut, including its lint gate, ran 46s up to the push. The note, its
